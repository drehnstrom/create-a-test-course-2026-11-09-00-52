# Course Title: Create a Test Course (1 hour)

## Course Description

Testing automated course generation pipelines requires a lightweight, predictable course structure that exercises all pipeline stages without adding unnecessary domain complexity.

This course serves as a simple test subject to verify end-to-end slide generation, lab structure, and publishing workflows across the training platform.

## Learning Objectives

- Verify the training course creation and publication pipeline using a streamlined test course
- Explore the structure, roles, and components of the course pipeline
- Validate course generation and review automated pipeline outputs

## Who Should Attend

Anyone testing or validating the automated course generation and delivery pipeline.

## Prerequisites

- None

## Hands-On Activities

- Lab: Testing the Course Pipeline

## Course Outline

**Module 1: Pipeline Fundamentals**

- Introduction to Course Pipelines
- Pipeline Architecture and Components
- Expected Inputs and Artifacts

**Module 2: Pipeline Execution and Verification**

- Executing the Generation Workflow
- Validating Generated Assets
- Lab: Testing the Course Pipeline
